Each package's API reference is automatically generated from its TypeScript source code and
include all exported types, functions, and classes, along with their documentation comments.
The references are available on [npmx.dev](https://npmx.dev).

The package root exports are the main public API. Client contract generation is
available from `@rest-rpc/core/generate`, as documented in
[Client Contract Generation](/docs/client/contract-generation). Other subpath-only
exports are implementation details and may change.
