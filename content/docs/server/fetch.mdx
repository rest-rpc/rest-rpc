---
title: Fetch Runtime
description: Use rest-rpc with Fetch API on the server
---

The Fetch adapter turns a Fetch `Request` into a `Response`. Use it with
fetch-native runtimes such as Bun, Deno, and Cloudflare Workers, or inside a
catch-all route of another framework.

## Install

```sh
pnpm add @rest-rpc/fetch
```

## Usage

```ts
import { route, createRouteHandler } from "@rest-rpc/fetch";
import { z } from "zod";

const todos = new Map([["todo_1", { id: "todo_1", title: "Write docs" }]]);

const getTodo = route
	.get("/todos/:id")
	.params(z.object({ id: z.string() }))
	.handler(({ params }) => {
		const todo = todos.get(params.id);
		return todo
			? { status: 200, body: todo }
			: { status: 404, body: { code: "TODO_NOT_FOUND" as const } };
	});

export const routes = { todos: { get: getTodo } };

const handler = createRouteHandler(routes, { prefix: "/api" });

const server = Bun.serve({
	routes: {
		"/api/*": async (request) => {
			const result = await handler(request);
			return result.matched
				? result.response
				: new Response("Not found", { status: 404 });
		},
	},
});

console.log(`Server running at ${server.url}`);
```

The handler resolves to `{ matched: true, response }` when the request matches a
route, and `{ matched: false }` otherwise, so the surrounding runtime can
provide fallback routing.

## Framework Context

Handlers and middleware receive the Fetch `request` in addition to the
[common handler arguments](/docs/route-builder#handler-arguments):

```ts
const getTodo = route
	.get("/todos/:id")
	.params(z.object({ id: z.string() }))
	.handler(({ params, request }) => {
		console.log(request.headers.get("x-request-id"));
		return todos.get(params.id);
	});
```

When your runtime passes a `Request` subtype, augment `DefaultRequest` to type
it. The handler then accepts and exposes that type:

```ts
import type { BunRequest } from "bun";

declare module "@rest-rpc/fetch" {
	interface DefaultRequest extends BunRequest {}
}
```

To share an application [context](/docs/context) type across routes, augment
`DefaultContext` in `@rest-rpc/fetch`.

## Options

```ts
type CreateFetchHandlerOptions = {
	bodyCodecs?: readonly BodyCodec<DefaultRequest>[];
	disableRequestValidation?: boolean;
	disableResponseValidation?: boolean;
	prefix?: `/${string}`;
	requestBodyLimit?: number;
	requestValidationErrorHandler?: RequestValidationErrorHandler;
	responseValidationErrorHandler?: ResponseValidationErrorHandler;
};
```

- `prefix`: path prefix prepended to every route path when matching requests.
- `bodyCodecs`, `requestBodyLimit`: see [Request and Response Bodies](#request-and-response-bodies).
- `disableRequestValidation`, `disableResponseValidation`: see
  [Disabling Server Validation](/docs/http-behavior/schemas#disabling-server-validation).
- `requestValidationErrorHandler`, `responseValidationErrorHandler`: see [Error Handling](#error-handling).

## Request and Response Bodies

The adapter decodes request bodies with the
[default codecs](/docs/http-behavior/serialization#default-codecs). Built-in
decoding reads at most `requestBodyLimit` bytes, `1 MiB` by default. A custom
codec's `deserialize` receives the `Request` and is not subject to
`requestBodyLimit`.

Handlers can return any value supported by the default codecs. A custom
serializer's `body` must be a Fetch `Response` body, such as a string, `Blob`,
`FormData`, byte array, or `ReadableStream`.

## Error Handling

Use `requestValidationErrorHandler` and `responseValidationErrorHandler` to
replace the [default validation error responses](/docs/http-behavior/errors).
Other errors reject the handler promise.

```ts
const handler = createRouteHandler(routes, {
	requestValidationErrorHandler: (error, request) => {
		return Response.json(
			{ code: "VALIDATION_ERROR", issues: error.issues },
			{ status: 422 },
		);
	},
	responseValidationErrorHandler: (_error, request) => {
		return Response.json({ code: "INVALID_RESPONSE" }, { status: 500 });
	},
});

export default {
	async fetch(request: Request) {
		try {
			const result = await handler(request);
			return result.matched
				? result.response
				: new Response("Not found", { status: 404 });
		} catch (error) {
			return Response.json({ code: "INTERNAL_SERVER_ERROR" }, { status: 500 });
		}
	},
};
```
