title: Quickstart
description: Define one contract, implement it on the server, and call it from a client.
---

This guide builds one `todos.create` route from a shared contract.

<Steps>
	<Step title="Install packages">
		Add the core package, a schema library, and the adapter for the server
		framework you want to use.
	</Step>
	<Step title="Define the contract">
		Declare the HTTP method, path, request body, and response body once in a
		file that both server and client code can import.
	</Step>
	<Step title="Implement the server route">
		Use the same route tree to write a typed handler for Express, Fastify, Hono,
		NestJS, Next.js, or a fetch-native runtime.
	</Step>
	<Step title="Call it from the client">
		Create a typed fetch client or TanStack Query helpers from the same
		contract.
	</Step>
</Steps>

## Install Packages

This guide uses Zod and Express by default. The same contract works with the
other server tabs below.

<Tabs>
<Tab title="pnpm">

```bash
pnpm add @rest-rpc/core @rest-rpc/express express zod
```

</Tab>
<Tab title="npm">

```bash
npm install @rest-rpc/core @rest-rpc/express express zod
```

</Tab>
<Tab title="yarn">

```bash
yarn add @rest-rpc/core @rest-rpc/express express zod
```

</Tab>
<Tab title="bun">

```bash
bun add @rest-rpc/core @rest-rpc/express express zod
```

</Tab>
</Tabs>

If you use another server tab, replace `@rest-rpc/express express` with the
adapter and framework package you need:

- Fastify: `@rest-rpc/fastify fastify`
- Hono: `@rest-rpc/hono hono`
- NestJS: `@rest-rpc/nest @nestjs/common @nestjs/core @nestjs/platform-express reflect-metadata rxjs`
- Next.js: `@rest-rpc/next`
- Web `Request`/`Response`: `@rest-rpc/web`

For the TanStack Query client example, also install:

```bash
pnpm add @rest-rpc/tanstack-query @tanstack/react-query
```

## Define A Contract

Create a shared contract file. Put it somewhere both your server and client can
import.

<Tabs>
<Tab title="Zod">

```ts contract.ts
import { router } from "@rest-rpc/core";
import { z } from "zod";

const todoSchema = z.object({
	id: z.string(),
	title: z.string(),
	completed: z.boolean(),
});

export const api = router({
	todos: {
		create: {
			method: "POST",
			path: "/todos",
			body: {
				title: z.string().min(1),
			},
			response: todoSchema,
		},
	},
});
```

</Tab>

## Server implementation

Implement the contract on the server with the framework of your choice.

<Tabs param="server">
<Tab title="Express">

```ts twoslash
// ---cut-start---
// @filename: contract.ts
import { router } from "@rest-rpc/core";
import { z } from "zod";

const todoSchema = z.object({
	id: z.string(),
	title: z.string(),
	completed: z.boolean(),
});

export const api = router({
	todos: {
		create: {
			method: "POST",
			path: "/todos",
			body: {
				title: z.string().min(1),
			},
			response: todoSchema,
		},
	},
});

// @filename: server.ts
// ---cut-end---
import { registerRoutes, router } from "@rest-rpc/express";
import express from "express";
import { api } from "./contract";

const app = express();
app.use(express.json());

const todos = new Map<
	string,
	{
		id: string;
		title: string;
		completed: boolean;
	}
>();

const routes = router(api, {
	todos: {
		create({ title }) {
			const todo = {
				id: crypto.randomUUID(),
				title,
				completed: false,
			};

			todos.set(todo.id, todo);

			return todo;
		},
	},
});

registerRoutes(app, routes);

app.listen(3000);
```

<Tab title="NestJS">

```ts twoslash
// @experimentalDecorators: true
// ---cut-start---
// @filename: contract.ts
import { router } from "@rest-rpc/core";
import { z } from "zod";

const todoSchema = z.object({
	id: z.string(),
	title: z.string(),
	completed: z.boolean(),
});

export const api = router({
	todos: {
		create: {
			method: "POST",
			path: "/todos",
			body: {
				title: z.string().min(1),
			},
			response: todoSchema,
		},
	},
});

// @filename: server.ts
// ---cut-end---
import "reflect-metadata";
import { Controller, Injectable, Module } from "@nestjs/common";
import { NestFactory } from "@nestjs/core";
import {
	RestRpcModule,
	Router,
	type RouteHandlers,
	type RouteRequest,
	router,
} from "@rest-rpc/nest";
import { api } from "./contract";

@Injectable()
class TodoService implements RouteHandlers<typeof api.todos> {
	private readonly todos = new Map<
		string,
		{
			id: string;
			title: string;
			completed: boolean;
		}
	>();

	create({ title }: RouteRequest<typeof api.todos.create>) {
		const todo = {
			id: crypto.randomUUID(),
			title,
			completed: false,
		};

		this.todos.set(todo.id, todo);

		return todo;
	}
}

@Controller()
class TodoController {
	constructor(private readonly todos: TodoService) {}

	@Router(api.todos)
	todosRouter() {
		return router(api.todos, this.todos);
	}
}

@Module({
	imports: [RestRpcModule.forRoot()],
	controllers: [TodoController],
	providers: [TodoService],
})
class AppModule {}

const app = await NestFactory.create(AppModule);
await app.listen(3000);
```

## Client implementation

Use the same contract to create a typed client.

<Tabs>
<Tab title="Fetch Client">

```ts twoslash
// ---cut-start---
// @filename: contract.ts
import { router } from "@rest-rpc/core";
import { z } from "zod";

const todoSchema = z.object({
	id: z.string(),
	title: z.string(),
	completed: z.boolean(),
});

export const api = router({
	todos: {
		create: {
			method: "POST",
			path: "/todos",
			body: {
				title: z.string().min(1),
			},
			response: todoSchema,
		},
	},
});

// @filename: client.ts
// ---cut-end---
import { initClient } from "@rest-rpc/core";
import { api } from "./contract";

const client = initClient(api, {
	baseUrl: "http://localhost:3000",
});

const todo = await client.todos.create.fetch({
	title: "Ship v1",
});
```

const tq = initTanstackQuery(api, {
	baseUrl: "http://localhost:3000",

		},
	}),

createTodo.mutate({
	title: "Ship v1",
});
