## Request With JSON Body

Regular JSON request bodies are declared with `.body(schema)`. Fields from an
object schema are flattened into the client call and server handler by default.

```ts
export const api = {
	todos: {
		create: route
			.post("/todos")
			.body(
				z.object({
					title: z.string().min(1),
					labels: z.array(z.string()).optional(),
				}),
			)
			.response(201, todoSchema),
	},
};
```

```ts
export const routes = router(api, {
	todos: {
		create({ title, labels }) {
			return createTodo({ title, labels });
		},
	},
});
```

```ts
const todo = await client.todos.create.fetch({
	title: "Write docs",
	labels: ["docs"],
});
```

## Request Without Body

Declare a request without a body by omitting a body setter.

```ts
export const api = {
	todos: {
		list: route
			.get("/todos")
			.query(
				z.object({
					limit: z.number().optional(),
				}),
			)
			.response(200, z.array(todoSchema)),
		byId: route
			.get("/todos/:id")
			.params(z.object({ id: z.string() }))
			.response(200, todoSchema),
	},
};
```

```ts
export const routes = router(api, {
	todos: {
		list({ limit }) {
			return listTodos({ limit });
		},
		byId({ id }) {
			return getTodoById({ id });
		},
	},
});
```

## Request With Form Body

Use `.formBody()` for `application/x-www-form-urlencoded` request bodies.
The body is sent as `URLSearchParams` and then passed to the handler as a
validated object under `body`.

```ts
import { route } from "@rest-rpc/core";

export const api = {
	forms: {
		submit: route
			.post("/forms")
			.formBody(
				z.object({
					title: z.string(),
					count: z.coerce.number(),
					remember: z.string().optional(),
					tags: z.array(z.string()).optional(),
				}),
			)
			.response(
				201,
				z.object({
					title: z.string(),
					count: z.number(),
				}),
			),
	},
};
```

```ts
export const routes = router(api, {
	forms: {
		submit({ body }) {
			return {
				title: body.title,
				count: body.count,
			};
		},
	},
});
```

```ts
const result = await client.forms.submit.fetch({
	body: {
		title: "Write docs",
		count: 3,
		tags: ["typescript", "rpc"],
	},
});
```

Server body parsers should pass a `URLSearchParams` instance to rest-rpc for
form bodies. Each present form key is passed to the schema as a string; omitted
keys are absent from the validation input. Array fields are inferred from
supported schemas and encoded or decoded as repeated form keys, such as
`tags=typescript&tags=rpc`.

When the array keys cannot be inferred, declare them explicitly with the
`arrayKeys` option.

```ts
route
	.post("/forms")
	.formBody({
		schema: type<{ title: string; tags: string[] }>(),
		arrayKeys: ["tags"],
	})
	.response(204);
```

## Request With Multipart Body

Use `.multipartBody()` for `multipart/form-data` request bodies.
The body is sent as `FormData` and then passed to the handler as a validated
object under `body`.

```ts
import { route } from "@rest-rpc/core";

export const api = {
	uploads: {
		create: route
			.post("/uploads")
			.multipartBody(
				z.object({
					title: z.string(),
					file: z.instanceof(File),
					tags: z.array(z.string()).optional(),
				}),
			)
			.response(
				201,
				z.object({
					title: z.string(),
				}),
			),
	},
};
```

```ts
export const routes = router(api, {
	uploads: {
		create({ body }) {
			return {
				title: body.title,
			};
		},
	},
});
```

```ts
const result = await client.uploads.create.fetch({
	body: {
		title: "Write docs",
		file,
		tags: ["typescript", "rpc"],
	},
});
```

Server body parsers should pass a `FormData` instance to rest-rpc for multipart
bodies. Each scalar key is passed to its schema as a string or `File`; omitted
keys are absent from the validation input. Array fields are inferred from
supported schemas and encoded or decoded as repeated form keys.

When the array keys cannot be inferred, declare them explicitly with the
`arrayKeys` option.

```ts
route
	.post("/uploads")
	.multipartBody({
		schema: type<{ title: string; file: File; tags: string[] }>(),
		arrayKeys: ["tags"],
	})
	.response(204);
```

## Request With Custom Content Type

Custom request bodies are declared with `.customBody()`. The complete payload
is exposed under `body` at the client call and server handler.

```ts
import { route } from "@rest-rpc/core";

export const api = {
	imports: {
		csv: route
			.post("/imports.csv")
			.customBody({
				contentType: "text/csv",
				schema: z.string(),
			})
			.response(
				201,
				z.object({
					imported: z.number(),
				}),
			),
	},
};
```

```ts
export const routes = router(api, {
	imports: {
		csv({ body }) {
			return importCsv(body);
		},
	},
});
```

```ts
const result = await client.imports.csv.fetch({
	body: "id,title\n1,Write docs\n",
});
```

## Request With Multiple Custom Content Types

Pass an array of content types to `.customBody()` to declare multiple custom
request content types.
The `body` value contains both the selected `contentType` and the `payload`.

```ts
export const api = {
	images: {
		upload: route
			.post("/images")
			.customBody({
				contentType: ["image/png", "image/jpeg"],
				schema: z.instanceof(Uint8Array),
			})
			.response(
				201,
				z.object({
					id: z.string(),
				}),
			),
	},
};
```

```ts
export const routes = router(api, {
	images: {
		upload({ body }) {
			return saveImage({
				contentType: body.contentType,
				bytes: body.payload,
			});
		},
	},
});
```

```ts
const image = await client.images.upload.fetch({
	body: {
		contentType: "image/png",
		payload: bytes,
	},
});
```

## Request With Fetch-Managed Content Type

Omit `contentType` when the request body should be passed directly to `fetch`
and the runtime should decide the `content-type` header.

```ts
export const api = {
	forms: {
		submit: route
			.post("/forms")
			.customBody(z.instanceof(URLSearchParams))
			.response(
				201,
				z.object({
					title: z.string(),
				}),
			),
	},
};
```

```ts
export const routes = router(api, {
	forms: {
		submit({ body }) {
			return {
				title: body.get("title") ?? "",
			};
		},
	},
});
```

```ts
const result = await client.forms.submit.fetch({
	body: new URLSearchParams({
		title: "Write docs",
	}),
});
```
