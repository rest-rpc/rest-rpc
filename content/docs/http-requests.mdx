## Request With JSON Body

Regular JSON request bodies are declared with a schema.
The `body` key is flattened for client call and server handler.

```ts
export const api = {
	todos: {
		create: route
			.post("/todos")
			.body(
				z.object({
					title: z.string().min(1),
					labels: z.array(z.string()).optional(),
				}),
			)
			.response(201, todoSchema),
	},
};
```

```ts
export const routes = router(api, {
	todos: {
		create({ title, labels }) {
			return createTodo({ title, labels });
		},
	},
});
```

```ts
const todo = await client.todos.create.fetch({
	title: "Write docs",
	labels: ["docs"],
});
```

## Request Without Body

Request without a body can be declared by omitting the `body` key or by using `noBody()` explicitly.

```ts
import { noBody } from "@rest-rpc/core";

export const api = {
	todos: {
		list: route
			.get("/todos")
			.query(
				z.object({
					limit: z.number().optional(),
				}),
			)
			.response(200, z.array(todoSchema)),
		byId: route.get("/todos/:id").body(noBody()).response(200, todoSchema),
	},
};
```

```ts
export const routes = router(api, {
	todos: {
		list({ limit }) {
			return listTodos({ limit });
		},
		byId({ id }) {
			return getTodoById({ id });
		},
	},
});
```

## Request With Form Body

Use `formBody()` for `application/x-www-form-urlencoded` request bodies.
Body is sent as a `URLSearchParams` to server and is then passed as validated
object to the handler.

```ts
import { formBody, route } from "@rest-rpc/core";

export const api = {
	forms: {
		submit: route
			.post("/forms")
			.body(
				formBody(
					z.object({
						title: z.string(),
						count: z.coerce.number(),
						remember: z.string().optional(),
						tags: z.array(z.string()).optional(),
					}),
				),
			)
			.response(
				201,
				z.object({
					title: z.string(),
					count: z.number(),
				}),
			),
	},
};
```

```ts
export const routes = router(api, {
	forms: {
		submit({ body }) {
			return {
				title: body.title,
				count: body.count,
			};
		},
	},
});
```

```ts
const result = await client.forms.submit.fetch({
	body: {
		title: "Write docs",
		count: 3,
		tags: ["typescript", "rpc"],
	},
});
```

Server body parsers should pass a `URLSearchParams` instance to rest-rpc for
form bodies. Each present form key is passed to the schema as a string; omitted
keys are absent from the validation input. Array fields are inferred from
supported schemas and encoded or decoded as repeated form keys, such as
`tags=typescript&tags=rpc`.

When the array keys cannot be inferred, you can declare them explicitly with the `arrayKeys` option.

```ts
formBody({
	schema: type<{ title: string; tags: string[] }>(),
	arrayKeys: ["tags"],
});
```

## Request With Multipart Body

Use `multipartBody()` for `multipart/form-data` request bodies.
Body is sent as `FormData` to the server and is then passed as a validated
object to the handler.

```ts
import { multipartBody, route } from "@rest-rpc/core";

export const api = {
	uploads: {
		create: route
			.post("/uploads")
			.body(
				multipartBody(
					z.object({
						title: z.string(),
						file: z.instanceof(File),
						tags: z.array(z.string()).optional(),
					}),
				),
			)
			.response(
				201,
				z.object({
					title: z.string(),
				}),
			),
	},
};
```

```ts
export const routes = router(api, {
	uploads: {
		create({ body }) {
			return {
				title: body.title,
			};
		},
	},
});
```

```ts
const result = await client.uploads.create.fetch({
	body: {
		title: "Write docs",
		file,
		tags: ["typescript", "rpc"],
	},
});
```

Server body parsers should pass a `FormData` instance to rest-rpc for multipart
bodies. Each scalar key is passed to its schema as a string or `File`; omitted
keys are absent from the validation input. Array fields are inferred from
supported schemas and encoded or decoded as repeated form keys.

When the array keys cannot be inferred, declare them explicitly with the
`arrayKeys` option.

```ts
multipartBody({
	schema: type<{ title: string; file: File; tags: string[] }>(),
	arrayKeys: ["tags"],
});
```

## Request With Custom Content Type

Custom request bodies are declared with `customBody()`.
The `body` key is not flattened for client call and server handler.

```ts
import { customBody, route } from "@rest-rpc/core";

export const api = {
	imports: {
		csv: route
			.post("/imports.csv")
			.body(
				customBody({
					contentType: "text/csv",
					schema: z.string(),
				}),
			)
			.response(
				201,
				z.object({
					imported: z.number(),
				}),
			),
	},
};
```

```ts
export const routes = router(api, {
	imports: {
		csv({ body }) {
			return importCsv(body);
		},
	},
});
```

```ts
const result = await client.imports.csv.fetch({
	body: "id,title\n1,Write docs\n",
});
```

## Request With Multiple Custom Content Types

Custom request bodies with multiple content types are declared with `customBody()` with an array of content types.
The `body` key is not flattened for client call and server handler. It contains both the `contentType` and the `payload`.

```ts
export const api = {
	images: {
		upload: route
			.post("/images")
			.body(
				customBody({
					contentType: ["image/png", "image/jpeg"],
					schema: z.instanceof(Uint8Array),
				}),
			)
			.response(
				201,
				z.object({
					id: z.string(),
				}),
			),
	},
};
```

```ts
export const routes = router(api, {
	images: {
		upload({ body }) {
			return saveImage({
				contentType: body.contentType,
				bytes: body.payload,
			});
		},
	},
});
```

```ts
const image = await client.images.upload.fetch({
	body: {
		contentType: "image/png",
		payload: bytes,
	},
});
```

## Request With Fetch-Managed Content Type

Omit `contentType` when the request body should be passed directly to `fetch`
and the runtime should decide the `content-type` header.

```ts
export const api = {
	forms: {
		submit: route
			.post("/forms")
			.body(customBody(z.instanceof(URLSearchParams)))
			.response(
				201,
				z.object({
					title: z.string(),
				}),
			),
	},
};
```

```ts
export const routes = router(api, {
	forms: {
		submit({ body }) {
			return {
				title: body.get("title") ?? "",
			};
		},
	},
});
```

```ts
const result = await client.forms.submit.fetch({
	body: new URLSearchParams({
		title: "Write docs",
	}),
});
```
